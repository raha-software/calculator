# Simple Calculator (Python)

A simple command-line calculator written in Python — my first Python project. I previously built several projects in C#.

## Features

- Addition, subtraction, multiplication, and division
- Division-by-zero error handling
- Continuous calculation (chain operations using the previous result)

## How to Run

    git clone https://github.com/raha-software/calculator.git
    cd calculator
    python calculator.py

## Example Output

    Simple Calculator
    Available operations: +  -  *  /
    Type 'exit' to quit.

    Enter first number: 12
    Enter operation (+, -, *, /): *
    Enter second number: 3
    Result: 12 * 3 = 36
